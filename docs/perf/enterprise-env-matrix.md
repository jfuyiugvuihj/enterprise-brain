## 1. "像企业"是三个维度，我们目前只有一个都不满足

| 维度 | 企业真实情况 | 我们现在的替代 | 缺口 |
|---|---|---|---|
| **算力** | Xeon + 单卡/多卡 A100/4090，几十 GB 显存，机房网络 | 笔记本 CPU 推理 | **可以租**（本文 §4） |
| **形态** | 断外网、内网域名 + HTTPS、几十账号、有备份盘、时钟不由我们定 | 本机 Docker Desktop，全程联网、只有一个 admin | **云上可造**，且这才是私有化的真考题 |
| **行为** | 50–5000 人、每天几百问、30–40% 重复、30–40% 多轮、70:25:5 的问答/分析/报告配比 | 手工提 3 个问题 | **只能合成**（本文 §3） |

### 1.1 形态维度里，**我们现在完全没有**的那一项：72 小时长跑
- 多轮对话累积会撞 **`context_length: 4096` 硬顶**（W8 §3.2.1 `[实测]`）；
- **子图 checkpoint 累积**（W8 P-6 已立单）；
- `chroma_db/` 运行期持续增长（191 MB 已被跟踪且被写脏）；
- 幽灵表类问题（`documents` 只插不删——已修 `app/documents/catalog.py:614-618`，但**同类问题只有长跑能再抓出来**）。

短时验收一律"全绿"，长跑必然第一次暴露。**这是 E5 档存在的唯一理由，不能省。**

## 3. 行为仿真：语料与工作日历（这一节决定数字有没有意义）

### 3.1 合成语料
- **6–8 个部门 × 3 个密级 × 4 类文档 × 三档规模（500 / 5 000 / 50 000 篇）**；
- **必含"同一指标、两个部门口径冲突"的成对文档**——这是本项目真正的差异化考题，
  没有它，"两说并陈 + 给来源"这条能力永远测不到；
- 只用 `test_rag_documents/` 手法造**假**文档（§6 红线）。

### 3.2 工作日历回放
| 参数 | 取值 | 依据 |
|---|---|---|
| 每人每天提问 | 20–50 | `[推算]` 企业知识工作者 |
| 重复率 | **30–40%，幂律分布** | `[外部基准]` 企业搜索普遍结论；直连 R35 缓存收益测算 |
| 多轮占比 | 30–40% | 直连 `chat.py:936`（带 session 不走缓存）与 4096 撞顶 |

## 4. 优云智算：下单前必须知道的六条事实（已核，别二次踩）

| # | 事实 | 影响 |
|---|---|---|
| 1 | **容器实例**给 root 与 `-p` 端口映射（23 元档）；**虚机**是 ubuntu/22 | 我们要跑 Docker ⇒ **必须虚机** |
| 2 | **装 Docker 只能用系统镜像的虚机**（FAQ 4.1 原文） | 容器实例方案直接排除 |
| 3 | **公共模型库只有容器实例能挂**（`/models`，`vllm serve <path>`），且默认只有华北二A / 上海二B | ⇒ 想用现成 vLLM 权重，得跟"必须虚机"打架 ⇒ **虚机自己下模型**，把下载时间算进预算 |
| 4 | **只有华北二A 同时满足**：独立 IP + 端口/防火墙 + 社区镜像 + 数据盘 + 虚机 | 下单直接锁定华北二A |
| 5 | 价格 `[外部基准]`：4090-24G **2.15 元/h**、48G 3.3、A100 10.75、A800 7.36；无卡 2c4g 0.15、8c16g 0.6。按量**秒级计费 + 关机不收费**（盘/镜像继续计） | 见 §5 成本表 |
| 6 | 数据盘 0.0005 元/GB/h；自制镜像上限 300 GB、0.008 元/GB/日（虚机按系统盘计）；**按量实例关机 7 天回收**（更新公告写 10 天，**按 7 天保守**）；**定时关机**可防空转 | 忘开机 = 白丢一轮；忘关机 = 白花钱 |

**两个必须避开的坑**：
- **禁用抢占式实例测延迟**——随时被回收、也不能关机免计费，测出来的 P95 是废的。
- 虚机是**裸机纯净环境，要手装 Nvidia 驱动**（`.run` 安装 + Nouveau / kernel-headers 坑）⇒
  **装完立刻做成私有镜像**，否则每次重来。

## 5. 成本（结论：整轮 <200 元，但下单/充值/实名**只能用户本人做**）

| 档 | 时长 | 单价 | 小计 |

| E1 无卡 8c16g | 4 h | 0.6 元/h | ≈2.4 元 |

| E3 同机换 vLLM | 4 h | 2.15 元/h | ≈9 元 |

## 6. Go / No-Go 判据（全绿才允许说"可交付企业"）

| 类别 | 判据 |
|---|---|
| 速度 | 问答档 P95 首屏 **≤1 s**、结论 **≤10 s**、缓存命中 **≤1 s**；分析档 P95 **≤45 s** 且每 ≤15 s 有进度；报告档 **100% 完成且可查回** |
| 安全 | 双身份越权 **0 条**（不是 99%）；缓存跨部门/跨密级命中 **0 条** |
| 可信 | 口径冲突题必须**两说并陈 + 各自来源**；任何降级路径（缺 embedding / 无 GPU / 无权限 / 真空列表）**四张脸在 UI 上可区分** |
| 质量 | 评测集分数**不退化**，且样本 **≥100 条**（现 30 条不足以报 P95） |
| 运维 | 72 h 长跑通过；备份→恢复演练通过；改时钟后 JWT 拒签；断外网可装可跑 |

**任何一条不过，对外材料里就不得出现对应承诺。**

## 7. 安全红线（租外部机器测私有化产品，这条最容易被忽略）

1. **只带 `test_rag_documents/` 假文档 + 探针账号**；
2. **不带** `chroma_db/`、**不带** `deploy/.env.server` 里的任何口令、**绝不带**客户真实数据；
3. 模型端口**一律走 SSH 隧道**，不裸奔 11434；
4. 用社区镜像必须先改**公开弱口令**（示例镜像自带 `compshare@126.com` 这类凭据）；
5. 测完：删实例 → 卸载并删数据盘 → 删自制镜像 → **关自动续费**；
6. 探针账号/文档测后删除并**复验**（沿用 r8 那轮的做法：`users` 仅剩 admin、catalog `[]`）。
