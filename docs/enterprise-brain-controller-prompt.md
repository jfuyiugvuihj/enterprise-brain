## 一、产品定位

企业智脑是私有化部署的企业 AI 智能分析平台。企业接入自己的文档和经营数据，员工在各自权限范围内，通过自然语言完成知识查询、数据分析、异常发现、辅助处理和成果交付。

它不是财务专用工具、通用OA或单纯的知识库聊天机器人。财务、销售、运营是应用场景，不为每个场景另造系统。目标是可信、完整、可重复的企业任务，不是增加菜单和模块数量。

保留私有化部署、本地模型优先、PGVector现役架构。不得擅自上传企业数据、启用远程模型回退或更换技术栈。

## 三、五个整体改进方向

### 1. 知识与数据协同

按业务需要连接：明确范围 → 检索与计算 → 展示依据 → 分析解释 → 图表报告。简单问题不强制调用全部模块。

明确文件、版本、期间、单位、筛选条件。数值来自可靠计算；制度判断有支持结论的原文、版本、生效时间和适用对象。追问、图表、报告保持数据和口径一致。

区分计算事实、文档明确规定、可能相关解释、尚待核实信息。关键歧义要确认，缺资料要说明，不猜数或编依据。

逐环检查文件选择、问题编辑、发送、执行、追问、图表、报告、成果回查的上下文传递。检查编辑问题是否丢选择、移除是否仍被使用、切任务是否串旧资料、文件更新是否静默换版本。

区分用户指定资料、系统实际读取/计算资料、真正支持结论的依据。每份指定资料要能说明已使用、未命中、不可访问、未就绪或未覆盖，不把“已选”说成“已阅读”。评估复用现有记录建立结构化文件、版本与范围传递的必要性。

### 2. 主动洞察与告警

从指标求和、阈值比较和泛泛解释，深化为有证据、可分析与处理的洞察。明确对象、期间、单位、当前值、阈值或比较基线；有数据支持时展示变化幅度、趋势、主要贡献维度和关联明细。

优先可解释阈值、预算偏差、同比环比，不扩张为复杂自动决策。没有历史数据只称阈值提醒，不虚构异常增长；贡献因素不冒充确定原因；AI解释必须依据计算与检索结果，不能只改提示词。

核实同对象同窗口异常去重、持续异常、恢复与人工关闭的区别、新数据重算及旧依据保留、从洞察进入分析时的同版本同口径，以及通知、负责人、处理记录和最终成果的关联。

复用现有确认、分派、关闭和审计，不另造处置系统。通知与告警出口未知或未隔离时，不执行会发送消息的复验。

### 3. 操作确认、制度核验与正式审批

明确区分：操作确认决定是否执行重要动作；制度核验判断材料是否符合企业文件；正式审批需要真实申请、审批人、流转和决定记录。

不把图表/PDF生成确认包装成经理审批，不把费用参数比较包装成完整审核。本轮不建通用OA；确需正式审批时先说明必要性及已有系统对接方案。

制度核验展示已核验事项、依据原文、缺失材料、无法判断项和风险建议，“未超金额标准”不等于全面合规。询问审批规定不得误触发费用预审，业务查询、核验、确认分别按真实意图执行。

评估按风险区分低风险分析与本地预览、敏感导出、对外发送、业务写入，减少重复确认。未经确认不撤现有安全边界；拒绝、取消、执行失败与成功分别呈现。

### 4. 权限与审计

权限由服务端控制，不靠提示词，也不能用用户批准代替。核查检索、计算、引用、图表、报告、下载、告警、续跑与历史访问的整条链。

续跑重新核验当前权限；跨部门检查正文、引用、明细、下载及元数据泄露。审计回答谁、何时、对什么资源做什么重要动作、授权/确认结果、实际执行结果；按需关联任务、版本、计算、确认和成果，复用现有标识。

不只记模型说成功或用户批准。审计自身有访问控制，不记录密码、令牌或不必要的完整敏感正文。区分业务审计与技术Trace，不为每步重复造账。

### 5. 成果质量与可追溯

报告是业务交付结果，不只是下载链接。复用现有记录说明输入与版本、口径、关键数字来源、引用和限制。

支持在明确上下文下继续追问、调整和重新生成；版本变化后旧结果仍可追溯。按任务和数据选择图表与报告结构，不为了出图而出图。不同报告类型分别验收，不外推费用模板。

## 四、代表任务

员工：查制度、看依据、追问适用条件；业务经理：分析变化、定位贡献因素、查看明细；管理人员：发现异常、组织处理、取得可复盘成果。这是验收方向，不新增三个模块。

按当前材料选首条任务；缺销售、库存等数据时不强行承诺。可先用合成费用资料验证通用机制，不因此收窄产品定位。

首条优先评估：部门负责人选择一份经营数据及相关制度，明确范围，计算事实并核验适用规则，展示依据与无法判断项，追问，生成报告，从成果中心回查原任务。先核对材料是否足以支持，再推荐。

## 六、验收

链路、数据、内容、呈现各判通过／不通过／未验；不适用说明原因。适用项未过不得宣布完成。

独立核算授权输入中的数字、单位、期间、筛选；原文支持引用结论；不同账号访问与下载一致；洞察不编增长和原因；确认、拒绝、取消、失败、成功准确；审计与执行一致；图表有信息价值；下载实际打开，PDF逐页看；追问、更新、重生保持可追溯。

多文件增加覆盖与未覆盖核查；追问范围保持；移除、清空、切任务不残留旧范围；更新不静默换版本；制度比较不触发错误预审。完整答案逐项回应，不能仅因正确数字或文件名出现而判通过。

HTTP200、退出码0、有图片、模型说成功均不足以宣布完成。合成资料不得冒充真人验收。遵守验证预算，不堆测试、账面文档或凭据纸。

真实复验授权须绑定环境、账号、对象、允许动作和状态变化；安全判断与历史许可不自动构成本轮授权。未知通知出口或可能影响其他任务时不执行。
