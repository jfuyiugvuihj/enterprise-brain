## C18 怎样接续，避免重跑

本目录 `c18-historical-candidates.json` 保存159条历史缓存候选的源码定位及当时结果标记，**不是159条当前失败**；部分已改名或已不存在。`c18-run-history.json` 记录具名小组、退出码、选择范围及原运行器汇总，包含先失败后修复的历史，不能累加成整体通过率。

最新本机指针 `20261027-111204-ee2aae` 的 passed 只指一条具名用例。旧长回归没有完整新汇总；没有把中断的长回归伪装成可恢复的 pytest 进程。

先列出待执行的具体用例和依赖。使用现有本机控制脚本：

```powershell
.\.venv\Scripts\python.exe scripts/run_c18_once.py status
.\.venv\Scripts\python.exe scripts/run_c18_once.py plan --serial --case tests/具体文件.py::具体用例
.\.venv\Scripts\python.exe scripts/run_c18_once.py start --serial --case tests/具体文件.py::具体用例
```

以上用例名是占位示例，先从候选与源码选择真实名字。`status` 不启动测试；`plan` 预估的是本次选定范围。执行前告诉业主选了哪些用例、预估区间和资源占用。小组验证遵守仓库预算；长回归另约空闲窗口，不能随手无参数启动全仓。默认不设置强制截止时间；延长、停止须按既有脚本状态和业主授权操作。进度、用例完成、失败和中断保存在 `output/c18-local-runs/`；新机器不能复制旧PID或锁当作仍在运行。

## 手机桌面图标现在是什么状态

已实现登录页及手机“我的”菜单中的“添加到手机桌面”，manifest、192/512图标和Apple触屏图标已在源码内。Android 按浏览器菜单添加；iPhone 用 Safari 分享菜单添加；微信先转外部浏览器。点击桌面图标打开企业智脑，仍需可访问企业内网，登录状态失效时仍须登录。

这不是原生 APK 或小程序；当前没有 service worker 或离线业务缓存。HTTP 内网地址在部分浏览器只创建普通网页快捷方式；manifest声明standalone不等于所有浏览器实机都已验证独立窗口安装。部署地址应稳定，变更地址会影响旧快捷方式；企业 HTTPS、证书信任和实际安装体验列入实机补验。
