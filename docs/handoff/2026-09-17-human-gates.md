  ```powershell
  docker run --rm --gpus all --entrypoint sh ollama/ollama:latest -c "ls -l /dev/dxg; ls /usr/lib/wsl/lib | head"
  ```

  - **看到** `/dev/dxg` 与 `libcuda.so.1` ⇒ 声明路线成立，R26 补完 `device_requests` 后走第二步。
  - **报 `could not select device driver`** ⇒ Docker Desktop 的 GPU 支持没开或 toolkit 没接上，

- **第二步（R26 落地后，真机验卡，需要 1 分钟停服）**：

  ```powershell
  docker compose up -d ollama
  docker logs --tail 50 enterprise-brain-ollama-1 | Select-String 'inference compute'
  ```

  **判据**：日志出现 `inference compute id=cuda`（现在是 `id=cpu library=cpu`）＝通过。
