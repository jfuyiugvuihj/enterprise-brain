# 人工闸门清单（Human Gates，2026-09-17）

**基线**：分支 `codex/data-file-catalog` @ `6ab523d`（H9 结案与 H10 在其后的文档提交中加入）。**作者**：总控线。
**用途**：登记**只有用户本人能做、Agent 不得代做**的事项。每项都给出**机械可核对的触发条件**，
供后续 Agent / 心跳提醒在当前时点判断"现在该不该叫人"，而不是靠记性或摘要。

**给 Agent 的规矩**
1. 本清单里被标 **仅用户本人** 的动作，任何 Agent 一律不得执行（含下单、push、删文件、改忽略规则）。
2. 提醒前先跑该项的 **核对命令**；**核对命令不满足触发条件就不许提醒**（防空转）。
3. 提醒时必须说清：哪一项、为什么现在要动、最短路径、不做的代价。一次只报已到触发点的项。
4. 状态变化后**就地改本文件的「当前」行**并附 commit 号，不要另开一份。

- **触发条件**：**没有"等阶段完成"这回事**——任何一次提交了成体系的工作（例如今天 `3f10b26` 的 1390 行文档）

- **不做的代价**：磁盘或机器故障 ⇒ 代码、全部文档、两周协作记录**一起没了**。这一项的风险高于其它所有项。
