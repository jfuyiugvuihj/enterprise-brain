# 企业智脑前端视觉升级设计

日期：2026-09-09

## 目标

将当前“样式未落地、默认块级堆叠”的界面升级为可用于真实企业场景的安全分析工作台。重点不是增加功能，而是让登录、导航、业务面板和对话区在视觉上形成统一产品。

## 视觉方向

- **定位**：面向企业管理者和分析人员的本地智能工作台。
- **气质**：克制、可靠、专业，不使用泛滥的科技霓虹或大面积渐变。
- **主色**：墨蓝背景、雾灰画布、青绿色状态色、蓝紫操作色、琥珀审批色。
- **字体**：中文优先使用系统无衬线字体；英文品牌使用紧凑的等宽/窄体字效果。
- **圆角**：页面容器使用 20px 左右，业务卡片使用 14–16px，按钮保持清晰的点击边界。
- **动效**：只保留导航切换、卡片悬停、登录进入和加载反馈；尊重 `prefers-reduced-motion`。

## 页面结构

### 登录页

采用左右分栏：

```text
┌──────────────────────────────┬──────────────────────┐
│ 品牌标识                      │ 登录卡片             │
│ 企业智脑                      │ 欢迎回来             │
│ 私有数据分析工作台            │ 用户名               │
│                              │ 密码                 │
│ 三项能力：本地 / 可追溯 / 权限 │ 进入工作台           │
│ 底部版本与运行状态            │ 管理员开通提示       │
└──────────────────────────────┴──────────────────────┘
```

左侧承担品牌与价值说明，右侧只承担登录任务。移动端改为单列，品牌区压缩为顶部横幅。

### 工作台

- 顶部栏：品牌、当前模块、用户身份、退出。
- 左侧栏：模块图标、名称、简短说明、当前选中状态。
- 主画布：模块标题条、状态信息、业务组件。
- 内容区域保持浅色或低对比深色卡片，避免所有层级都使用同一种深色。

### 业务面板

统一以下视觉契约：

- 面板标题使用“标题 + 描述 + 状态/动作”结构。
- 空状态必须说明下一步动作。
- 上传、筛选、确认、删除等危险或关键动作使用明确颜色和反馈。
- 表格、文件列表、图表和审批卡片共享相同的间距、边框和状态标签。

## 组件边界

- `App.vue`：只负责认证状态、工作台壳层和模块切换。
- `LoginView`：登录表单、错误提示、品牌信息。
- `WorkbenchShell`：顶部栏、侧边导航、主内容容器。
- 现有 `DashboardPanel`、`DocPanel`、`DataPanel`、`InsightPanel`、`GraphPanel`、`ApprovalPanel`、`ChatPanel`：保留业务逻辑，只统一外层视觉契约和交互状态。
- `theme.css`：只放全局变量、重置、公共控件和响应式规则。

本次优先采用小范围重构：先在现有 `App.vue` 中完成登录页和工作台壳层，避免同时迁移业务状态；业务面板逐个调整，确保前后端行为不受影响。

## 验收标准

1. 登录页不再出现全宽输入框、异常超大字体或未布局的块级元素。
2. 1440px、1024px、390px 宽度下布局均可用。
3. 登录失败、加载、退出和登录成功状态视觉明确。
4. 工作台七个模块具有一致的导航、标题、卡片和空状态风格。
5. 原有登录、上传、预览、问答、审批和导出功能不回归。
6. `npm run build` 通过。
7. 使用真实浏览器截图检查登录页和至少三个工作台模块。
