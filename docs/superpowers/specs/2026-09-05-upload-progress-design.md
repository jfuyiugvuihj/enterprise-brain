# 知识库上传进度展示设计

## 目标

让用户明确知道文件处于上传、解析入库还是已完成状态，避免只看到持续旋转图标而无法判断是否卡住。

## 方案

- 上传阶段使用 Axios `onUploadProgress` 显示真实百分比，进度范围为 0% 到 70%。
- 请求上传完成后进入“解析并入库”阶段，显示动态进度提示，不伪造精确解析百分比。
- 后端成功返回后显示 100% 和完成状态；失败时保留错误信息和失败状态。
- 多文件仍按现有顺序上传，每个文件独立显示状态。

## 验证

- 前端源码测试检查上传进度回调、阶段字段和完成 100% 状态。
- `npm run build` 验证 Vue 编译。
- Python 全量测试验证后端行为不回归。
