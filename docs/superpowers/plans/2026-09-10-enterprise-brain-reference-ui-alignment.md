## 目标

将前端从“深色通用工作台”改成参考图中的深蓝企业智能产品界面，重点对齐登录页与总览驾驶舱的版式、层级、颜色、信息密度和交互入口。

本次改版不改变后端 API、登录流程、文档上传、数据分析、洞察、图谱、审批和对话逻辑，只调整前端壳层、总览数据编排和视觉样式。

## 参考图拆解

### 登录页

- 使用整屏深蓝背景，不使用当前大块独立卡片包住左侧品牌区。
- 左上角显示企业智脑标识，包含中文名和 `ENTERPRISE BRAIN` 英文副标。
- 右上角显示“数据 × 知识 × AI，驱动更聪明的企业”。
- 左侧主视觉显示：
  - “私有化企业智能分析平台”
  - “让企业数据，成为生产力”
  - “数据安全 / 知识沉淀 / 智能分析”三项能力。
- 左侧背景加入低对比度的数字地球、轨迹线、节点和数据浮层，作为装饰，不承载业务数据。
- 右侧登录卡片显示欢迎语、用户名、密码、进入工作台、记住我和忘记密码。
- 登录错误仍使用现有错误状态，不显示技术堆栈。

### 工作台总览

- 页面采用固定左侧导航 + 右侧内容区，不显示当前顶部大块工作区标题占位。
- 左侧导航包含品牌、总览、文档、数据、洞察、图谱、审批、对话。
- 顶部工具栏显示当前页面、搜索入口、通知入口和用户信息。
- 总览内容按参考图组织为：
  1. 四张 KPI 卡片：文档总量、数据表、智能洞察、审批任务。
  2. 数据趋势区域：文档、数据、洞察三条趋势线；无历史趋势接口时使用当前数据生成静态比例线，不伪造业务日期结论。
  3. 异常与风险列表：使用现有洞察结果；没有结果时给出明确空状态。
  4. 最新文档：使用文档目录接口；显示最近文件和解析状态。
  5. 知识证据：使用当前指标口径查询结果；显示指标、来源和可信度。
  6. 快速操作：上传文档、数据分析、新建洞察、发起审批，点击后跳转现有模块。
- 参考图中的示例数字不直接写入业务状态。除装饰性占位趋势外，业务数字均来自现有 API 或空状态。

### 响应式

- 桌面优先对齐 1440px 参考图。
- 1024px 保持四张 KPI 卡片两列布局。
- 390px 移动端改为单列，左侧导航变为横向滚动导航，不产生横向页面溢出。
