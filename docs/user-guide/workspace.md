# 工作台

[返回总目录](README.md)

工作台用来了解当前账号可见的资料和异常概况，并选择业务起点。

| 模块 | 从哪里进入 | 下一步 |
|---|---|---|
| 资料与分析 | “准备资料”，或侧栏资料中心、智能助手 | 上传制度或经营表格，带入问题 |
| 异常与待办 | “查看异常与任务”，或侧栏异常提醒、待办事项 | 查看告警、核查、处理确认操作 |
| 成果交付 | “查看分析成果”，或侧栏成果中心 | 打开、下载、返回分析 |

账号和维护页面集中在“账号与系统管理”，展开后按角色显示。切换页面不会等于执行一次分析；要在智能助手核对问题并发送。

最新文档显示近期资料状态；异常与风险可跳转告警；快速操作用于进入对应页面。“知识证据”可查询指标口径：填写指标问题、点击查询、核对定义和来源。没有制度依据时，不能把匹配名称当成已验证口径。

工作台数字遵循当前账号权限和页面统计范围。活动趋势反映系统记录的资料、告警等活动，不能直接当作企业收入、利润或订单趋势；经营指标请用 [经营数据](analysis/datasets.md) 分析。

加载失败、未知、零条记录是不同状态。遇到错误先处理提示，不把空白当作“企业没有资料”。
