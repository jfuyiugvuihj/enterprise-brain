# 认识工作台

[返回使用帮助](README.md)

登录后，工作台会显示当前账号可见的资料、提醒和常用入口。按手头的事选择：

- **上传制度、手册或经营表**：点“准备资料”，或进入“资料中心”。
- **查资料、算数据、生成图表**：进入“智能助手”。
- **处理提醒和待确认操作**：点“查看异常与任务”。
- **找回图表或报告**：点“查看分析成果”，或进入“成果中心”。

手机端常用入口固定在页面底部：“问答”“资料”“成果”“消息”。其他页面可点“更多”打开导航；个人资料和使用帮助在“我的”里。

“最新文档”可以帮你确认刚上传的文件是否出现；“异常与风险”可以打开相关提醒。在“知识证据”中输入指标名称并查询，可查看系统找到的定义和来源。若只找到名称相近的条目，请打开原文件确认是否适用。

工作台上的数字只覆盖你有权查看的范围。“活动趋势”记录的是资料和提醒等系统活动；要分析收入、费用等经营变化，请进入 [经营数据](analysis/datasets.md)。

页面提示加载失败时，点重试。持续失败可把页面名称和发生时间告诉管理员。
