# 运行记录与维护读数

[返回账号与系统管理](README.md) · [总目录](../README.md)

## 运行记录

选择一次运行，查看保存的事件、阶段状态、分段耗时和独立计算记录。计算详情可追溯输入文件、版本、筛选口径、结果和关联成果，有权限时下载关联文件。

该页不重新执行任务；历史没有保存的记录无法事后补出。检查“服务端记录数”和页面读出数，缺失读数不能解释成零。

## 服务等级目标

点击“重新读取”，按知识问答、分析、报告类别查看目标、样本数、实测耗时和阶段情况。目标是期望，实测才是记录结果；欠样本、不可测、未记录都不能解释成达标。

请求类别、模型配置、性能档位各有含义。未分类历史请求独立统计；该页不直接修改目标和样本门槛。

## 评测报告

选择显示报告数，点击“重新读取”，查看已有报告、评测集、运行说明及文件状态。该页只读已保存结果，不提供“立即运行评测”。

结论只适用于对应日期、数据和环境，历史通过不能证明当前所有业务内容正确。

## 审计事件

按用户名、操作类型、处理结果、读取上限筛选，点击“查询”；“重置筛选”清除条件。类型和结果使用系统标识，不清楚可先留空查看记录。

核对匹配总数、返回数、上限和截断提示，不把前一段记录当全集。页面只读，覆盖范围由服务端实际记账决定，不假定每次成功操作都有事件。
