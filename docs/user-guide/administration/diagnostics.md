# 查看运行与审计记录

[返回账号与系统管理](README.md)

以下页面只对有相应权限的账号开放，展示已经保存的记录；点“重新读取”不会重新执行任务。

## 任务运行记录

找到要核对的任务，打开步骤状态、耗时及相关文件。涉及计算时，查看文件版本、筛选条件、结果和关联成果。旧任务若显示“未知”或“未记录”，表示当时没有保存这项信息。

## 服务等级目标和评测报告

在“服务等级目标”中点“重新读取”，按知识问答、分析和报告查看目标与已有记录。样本不足或显示无法测量时，先查看说明，不要把空白当作达标。

在“评测报告”中选择要显示的数量并点“重新读取”，可查看已有报告的日期、范围和文件状态。这里不能启动新评测；历史结果只说明对应日期和环境的情况。

## 审计事件

按用户名、操作类型或结果筛选，再点“查询”；用“重置筛选”清除条件。核对匹配总数、当前加载数及“还有更多”，需要时继续读取。这里能查看记录，不能修改记录。查不到预期动作时，先核对时间和筛选条件，再结合原任务排查。
