# 账号与角色

[返回账号与系统管理](README.md) · [总目录](../README.md)

系统管理员查看账号编号、用户名、角色、部门、创建时间。

## 开通

点击“开通账号”，填写账号名和初始密码，选择员工、部门负责人、管理员或审计人员，填写部门，提交后核对名册。初始凭据应通过企业认可方式交付，不写进公开文档。

## 修改和删除

先选“操作对象”，再点修改密码、调整部门或删除账号。改密弹窗有当前密码与新密码字段，按服务端要求填写并核对结果；不承诺免旧密码重置。调部门后检查资料可见范围。

当前页面暂不支持停用、改名、修改已有角色或任意自定义角色权限。删除与停用不同，确认正确对象后再执行。
