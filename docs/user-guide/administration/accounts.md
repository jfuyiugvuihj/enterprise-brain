# 管理账号与角色

[返回账号与系统管理](README.md)

此页面供系统管理员使用。操作前先核对账号名，完成后回列表查看结果。

## 开通账号

1. 点“开通账号”，填写账号名、初始密码和部门。
2. 选择员工、部门负责人、管理员或审计人员，提交。
3. 在列表中确认账号已出现，并通过企业认可的方式把初始密码交给本人。

## 修改现有账号

先选择“操作对象”，确认用户名，再选择“修改密码”“调整部门”“调整角色”或“删除账号”。修改密码需要填写该账号的当前密码和新密码。调整部门或角色后，请让账号本人重新访问相关页面，核对资料范围是否符合预期。

## 员工忘记密码时

1. 先按企业规定核实申请人的身份，再选择需要恢复的账号，点“重置密码”。
2. 设置至少6位的临时密码，重复输入一遍，核对弹窗里的账号名后点“确认重置”。这里不需要填写原密码。
3. 看到“密码已重置”后，通过企业认可的方式把临时密码交给本人。不要把密码发在任务评论、报告或共享文档里。

重置后，该账号原来的登录和下载凭据失效；其他账号不受影响。员工用临时密码登录后，需要先设置自己的新密码，再重新登录进入工作台。处理中或排队的旧任务可能被拒绝继续执行，请核对任务结果后重新发起；已经完成的操作不会被撤回，历史资料和成果保留。

如果提示名册未能重新读取，请点“重新加载”核对，不要连续重置多次。

“删除账号”会再次要求确认，请核对对象后执行。暂时限制访问请使用“停用账号”，不要先删除再重新开通。当前不能修改用户名。

## 暂停或恢复一个账号

1. 选择操作对象，核对账号名和当前状态。
2. 点“停用账号”，阅读弹窗里的影响后确认。看到“账号已停用”及更新后的状态，再通知相关人员。
3. 需要恢复时，选择该账号，点“恢复账号”并确认。本人须重新登录，访问范围仍按当前角色和部门确定。

停用会阻止新的登录和后续资料访问，保留已有资料、任务、成果与审计记录。已经完成的操作和已保存到设备的文件不会被撤回；被取消的任务不会自动重新开始。恢复后，原登录和旧的临时下载链接仍然失效。

系统会保留至少一个可用管理员。最后一个启用的管理员不能被停用、删除或降为其他角色；如需交接，先开通并确认另一名管理员能够登录。
