# 使用帮助

想做什么？从下面选一项开始。每篇指南都写明了操作入口、完成后的结果，以及遇到问题时该去哪里查。

## 常用任务

- [第一次登录](getting-started.md)：登录、退出，了解自己能看哪些资料。
- [查制度或比较文件](analysis/documents.md)：选择文档，在回答中打开引用原文。
- [分析经营表](analysis/datasets.md)：上传表格，检查字段，再提问或生成图表。
- [处理异常提醒](tasks/alerts.md)：查看触发依据，继续分析，记录处理结果。
- [处理待确认操作](tasks/approvals.md)：看清操作影响，批准或驳回，再查看执行结果。
- [找回报告](delivery/artifacts.md)：预览、下载，并核对文件内容。

需要按页面查找时，电脑端使用左侧目录；手机端点“浏览目录”。遇到错误可先看 [常见问题](troubleshooting.md)。

不同账号看到的资料和操作入口会有所不同。看不到需要的文件时，从 [我的账号](administration/profile.md) 核对角色与部门，再请企业管理员检查授权。
