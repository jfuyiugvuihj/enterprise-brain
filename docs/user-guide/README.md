## 三条完整操作路线

- 查询制度：知识库上传并确认可检索 → 勾选制度 → 提问 → 打开原文核对 → 追问或生成报告。
- 经营分析：上传经营表格 → 检查数据画像 → 选择模板并补充口径 → 计算出图 → 核对数字 → 确认导出 → 下载检查。
- 异常处置：登记规则 → 巡检产生告警 → 带着告警继续分析 → 处理待确认操作 → 回原告警指派或关闭。

页面入口是否可见和操作是否允许，以当前账号权限为准。上传成功、链路走通、下载成功分别只证明对应一步，不能代替内容核对。

本手册描述功能用法，不代表整个平台或所有业务场景已经通过验收。当前模型、检索、图表和报告的限制见 [常见问题](troubleshooting.md)。
