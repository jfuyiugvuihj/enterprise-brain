# 打开、下载和核对报告

[返回成果交付](README.md) · [智能助手](../analysis/assistant.md)

## 找回成果

分析完成后，在智能助手点“生成本次报告”。若出现确认卡，先阅读操作内容；生成结束后，可从原对话打开，也可进入“成果中心”。

**入口**：电脑端进入“成果中心”；手机端点底部“成果”。

1. 在“成果中心”按名称、时间、类型或来源查找。没看到时点“刷新”；页面出现“读取更多”时继续加载。
2. 点“打开”预览正文；需要保存时点“下载”。打开和下载都按当前账号的权限检查。
3. 若成果提供“返回分析会话”，可回到原问题继续追问。从异常提醒产生的报告也可返回原提醒。

**完成后**：浏览器显示报告预览，或把文件保存到设备。手机上点“打开”可在页面中翻阅 PDF；点“下载”后，浏览器可能显示文件、保存文件，或交给系统文件应用处理。请以实际保存的文件为准，不要只看下载按钮是否点过。

PDF 中的文字或表格太小时，点“放大”，再左右或上下滑动查看细节；电脑也可用预览区的滚动条移动。点“缩小”逐步缩回，或点“适合宽度”恢复整页宽度。百分比以适合当前窗口的宽度为100%；打开另一份文件时会恢复适宽。下载和关闭按钮保留在预览顶部。

## 交付前核对

- 数字是否与原表和分析正文一致？看清期间、筛选条件、单位及你有权查看的范围。
- 图表的标题、坐标、图例是否说明了实际统计内容？文档引用能否支持相应结论？
- 打开**下载后的文件**。PDF 从第一页翻到最后一页，检查空白、截断、遮挡和乱码。

发现错误，回原分析修正问题或资料后重新生成。要使用更新后的文件，请新建任务重新选择；旧成果保存的是生成当时的资料版本。缺少历史或预算数据时，报告也无法据此计算增长或预算差异。

报告可能按企业设置到期或清理。需要长期留存时，核对后下载到企业规定的位置。管理员删除成果时需要确认；删除成果不会删除原始资料。

**下载失败时**：先确认自己能打开这份成果，再核对文件是否仍在列表中、当前账号是否有下载权限。手机浏览器跳转后若空白，返回预览页重试；持续失败时，把浏览器名称、报告名和发生时间告诉管理员。
