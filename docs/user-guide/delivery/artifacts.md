## 生成与找回

在智能助手先核对分析，点击“生成本次报告”；出现确认卡时执行或拒绝。生成完成后可从聊天下载，也可进入成果中心查找。

成果中心列当前账号可访问的已登记图表和报告。点击“刷新”，按名称、时间、类型、来源和有效期定位；有“读取更多”时继续加载。点击打开或下载相关操作，需有资源权限。

有会话信息的成果可“返回分析会话”查看原问题和过程，并继续追问。历史成果缺少来源时不能从文件名猜出真实血缘。

阈值提醒发起的报告可返回原提醒；同一会话重新生成时，成果保留前一报告的关联。来源文件和版本、计算口径及限制应与原分析一致。比例、单价或编号不会当作可加总指标，未提供比较基线时不生成增长或预算偏差结论。

原分析中的图表从已登记成果装入PDF，按原引用顺序检查。图已失效或当前无权访问时，系统拒绝导出缺图报告；重新生成不会悄悄加入同一会话中的其他历史图。

制度联合核查可从服务端恢复所选经营表与参考文档。数据或制度更新后，旧成果仍保留生成时依据；继续原任务遇到版本变化会要求重新发起，不能把历史报告当成新版材料的结论。报告生成前的确认是操作授权，不是经理业务审批。

## 交付核对

1. 打开实际下载文件，检查能否正常阅读。
2. 比较原表、分析正文、图表与报告的数字。
3. 确认期间、筛选、授权范围、单位及制度版本。
4. 检查标题、图例、标签和引用是否支持结论。
5. PDF逐页检查截断、遮挡、空白和乱码。

有图或下载200不能代替这些检查。内容错误应修正原分析后重新生成。未标注金额单位的资料不能默认解释成人民币。

## 保存与删除

成果可能到期或清理，需要长期保存的文件核对后下载到企业规定位置。管理员删除需确认；删除成果不等于删除原始资料或整段会话。
