# 登录与权限

[返回使用帮助](README.md) · [认识工作台](workspace.md)

## 登录

1. 打开企业管理员提供的企业智脑地址。
2. 输入账号和密码，点“登录并进入工作台”。
3. 进入工作台后，确认页面显示的是自己的账号。

如果管理员刚帮你重置过密码，登录后会先显示“设置你的新密码”。输入收到的临时密码，设置一个与它不同、至少6位的新密码，重复输入后保存，再用新密码登录。暂时无法处理时可点“退出并稍后处理”；刷新页面也不会跳过这一步。

忘记密码时，点“忘记密码？”查看联系管理员的提示；目前没有邮件自助找回。登录失败，先检查地址、账号和密码；若页面提示服务不可用，记下发生时间并联系管理员。共用电脑用完后，点“退出登录”。

登录页可点“使用帮助”。登录后，电脑端从页面顶部进入帮助；手机端从“我的”菜单进入。

## 手机桌面快捷入口

用手机浏览器打开企业智脑，在登录页点“添加到手机桌面”，按照页面给出的浏览器步骤操作。Android 浏览器通常在菜单里选择“添加到桌面”或“添加到主屏幕”；iPhone 在 Safari 中点“分享”→“添加到主屏幕”。微信内打开时，先从菜单转到手机浏览器。

以后点桌面上的“企业智脑”图标即可进入。手机仍需能访问企业内网；有些浏览器会把快捷入口显示成普通网页，这是浏览器的呈现方式。

## 为什么有些资料看不到

系统按角色、部门和文件密级控制访问。默认情况下，员工可上传、查询、分析并下载自己有权访问的资料；部门负责人还可处理异常和待确认操作；管理员可管理账号和资源；审计人员可查看授权范围内的记录与资料。进入一个页面，不代表能打开其中每个文件。

员工、部门负责人、管理员和审计人员可查看的最高密级分别为 1、2、3、3 级。文件还会受所属部门等条件限制。若文件或下载入口不可用，打开 [我的账号](administration/profile.md) 核对角色和部门，再请管理员检查该文件的授权。不要借用他人账号。

经营表也受记录权限影响：两人分析同一份表，可能得到不同的合计。对比数字时，先确认双方使用的期间、筛选条件和可见记录范围。
