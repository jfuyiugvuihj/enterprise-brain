# 在智能助手提问

[返回资料与分析](README.md) · [查看成果](../delivery/artifacts.md)

## 选择任务和资料

**入口**：电脑端进入“智能助手”；手机端点底部“问答”。从文档或经营表上的“基于此文件提问”“分析这份数据”进入时，先检查系统带入的资料。

要查文件内容，选“知识问答”；要统计经营表，选“数据分析”；不确定时可用“系统判断”。需要整理已核对的分析时，再生成报告。

发送前看一下任务设置和右侧资料列表。数据表用于计算，参考文档用于查找原文；两者可以同时选择。若右侧留有上个问题的文件，可逐份“移除”或“清空参考文档”。

## 写问题并发送

写明要处理的对象、期间和结果。比如：“用已选费用表统计本季度已批准记录，按部门汇总金额和笔数，画出对比图；金额单位按原表标注。”点发送或按 Enter；Shift+Enter 换行。

**完成后**：页面出现本次回答。检查是否答到了问题、数字与图表是否一致，并打开引用查看原文。“处理详情与资料记录”可查看本次保存的文件、版本和计算信息。没有记录的旧任务，无法仅凭回答中的文件名还原当时使用的版本。

## 一次问多个问题

可以用①②③编号，也可以用问号分开。每道统计题都写清期间和指标，例如：“①2026-01金额合计是多少？②2026-02金额平均值是多少？”不要只在第一题写筛选条件，让系统猜后面的题是否沿用。

同时查制度和统计数据时，选好参考文档与经营表，再分别写出问题。制度回答应有原文依据；统计回答应有对应的期间、单位和数据版本。问到增长原因时，只有金额还不足以判断，需进一步提供可比期间、业务量等材料。

要报告时，请写“合成一份PDF报告”或“每题分别生成一份PDF报告”。未说明时，系统会先询问，再发起导出操作确认。常规统计与已完成的查询计算可以按题整理，例如合计、均值和中位数运算；查询结果需要有对应的计算记录，导出时会重新核对原版本与权限，缺少记录时会说明哪题未完成。联合制度核验或每题含图时，请先分别核对结果，不要把未生成的部分当作已经交付。完成后，在电脑端“成果中心”或手机端“成果”查看各份文件。

中位数、排名等查询需要图表时，写清分组和指标，例如：“2026-01-01至2026-02-28，按状态分别计算金额中位数，生成含图报告。”图表会使用导出时重新核对的查询结果，保留查询顺序；不要把输入字段的单位直接当成比值、方差等派生结果的单位。当前图表支持2至50项完整分类数值；只有一个总值、缺值、标签重复或多指标混在一起时，请先生成无图报告，或明确分组后重新查询。多题跨月时请写完整起止日期。

## 继续追问或换题

要改变期间、分组或进一步解释，可在原对话继续追问。发送前核对右侧仍选中了需要的资料。换一项独立工作时点“新建任务”；资料已更新、想使用新版本时，也请新建任务重新选择。

只改一道统计题时，可写：“把第二题的期间改为2026-04，其他不变”，或“把第二题的状态改为仅统计已批准，其他不变”。也可以重述这一题的期间、指标与筛选条件。系统保留其他题和原数据版本；原有部门、门槛等条件无法可靠拆分时，会先请你说明，不直接扩大统计范围。想换成资料的新版本，仍需新建任务重新选择。

“历史任务”可找回以前的对话；本机列表没有时，点“从服务器取回”。回到旧任务后，先核对当时保存的资料范围，再继续操作。

## 确认、取消与报告

出现操作确认卡时，阅读具体动作和影响，选择执行或拒绝。选择执行后，回到任务查看实际结果；确认通过并不表示生成已经成功。

需要停止时，点“中断本次回答”并确认。已完成的操作不会撤销，等待处理的确认事项也不会自动拒绝。关闭浏览器后任务也可能继续，回来可从原对话或成果中心查看状态。

要交付结果，先核对数字、单位、期间和引用，再点“生成本次报告”。报告完成后，到 [成果中心](../delivery/artifacts.md) 打开并检查文件。

**回答不符合预期时**：先看右侧实际选用的文件，再把期间、筛选条件或要比较的文件名写清楚。若引用没有支持结论，请打开原文核对，必要时缩小问题后重问。
