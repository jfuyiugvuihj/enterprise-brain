## 任务设置和发送

“系统判断”按题意选择处理方式；“知识问答”查授权资料；“数据分析”计算经营表格；“生成报告”生成可交付文件。

在任务设置中确认经营数据，必要时刷新文件列表。经营数据表和参考文档可以同时选择：数据用于计算，文档用于查找依据。选择数据表或分析模板会保留参考文档，发送前请分别核对两种输入；不需要文档时在右侧移除或清空。

问题最好写明对象、期间、筛选、指标和预期结果。例如：“按已选费用表，统计本季度已批准记录，按部门汇总金额与记录数，单位按原表标注，生成对比图。”Enter发送，Shift+Enter换行。

## 核对回答

回答逐步显示；右侧区分本轮实际用表、下一轮所选资料和实际检索引用。检查问题是否被回答、文件是否正确、范围与单位是否明确、数字与图表是否一致；点击来源打开原文。

选中多文档时，修改问题文本不会丢失所选范围。右侧可“打开核对”“移除”或“清空参考文档”；后两项改变下一轮范围，不改写已经完成的结果。

历史缺少实际用表记录时，正文记载的文件名只供核查。引用反馈不修改原文件、不立即重训模型，也不保证下一次回答变化。“处理详情与资料记录”可查看已保存的执行信息。

## 追问、历史与新任务

“继续追问”可改变分组、限定期间、解释算法。沿用参考范围时仍应核对右侧列表；更换主题推荐“新建任务”，避免混合上下文。

“历史任务”打开已有会话，“从服务器取回”读取服务端历史。刷新或切回会话会恢复已保存的参考文档范围；旧记录里没保存的信息无法凭空补齐。

制度联合核查会保留本任务的数据版本、制度版本与统计条件。追问可明确修改期间或状态；数据或制度更新后，不会静默使用新版继续出结论。需要改用新版时新建任务并重新选择资料。原表未注明单位或缺少提交日期、原始凭证等材料时，相关事项仍无法判断，不能把状态或金额比较视为全面合规。

## 确认和中断

出现操作确认卡时，阅读影响后执行或拒绝；也可到待办事项处理。批准是允许执行，不等于执行成功。

“中断本次回答”需要再次确认，会停止接收回答并请求取消后续处理；不会撤销已完成动作，也不会自动拒绝尚挂起的确认卡。取消标记可能阻止下一轮续跑，中断后的文本可能不完整。已完成的分析和成果保留，未完成步骤按实际回执显示取消或失败。

仅关闭或刷新浏览器不等于取消。已经确认的任务可能继续完成，返回后从会话、成果中心及运行记录核对实际结果。

## 生成报告

先核对结果，再点“生成本次报告”。该入口用本次分析原文排版，保留数值、范围、引用和限制。需要确认时处理卡片；完成后下载并逐页检查，方法见 [图表与报告](../delivery/artifacts.md)。
