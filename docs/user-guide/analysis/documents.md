# 上传和查询文档

[返回资料与分析](README.md) · [智能助手提问](assistant.md)

适用对象：有上传权限的员工。查看和下载已有文件时，还要符合该文件的访问权限。

## 上传文档

**入口**：电脑端进入“资料中心”→“知识文档”；手机端点底部“资料”→“知识文档”。

1. 打开“知识文档”。
2. 在“上传文档密级”选择这次文件的级别，再选择文件或拖入上传区。支持 PDF、DOCX、TXT、Markdown、XLSX 和 CSV，可一次选多份。
3. 逐份查看处理结果。显示“已可检索”后，就可以用文档内容提问。

**完成后**：新文件出现在列表中，状态显示“已可检索”。上传进度到 100% 只表示文件传完，内容处理可能还在继续。单个文件默认最多 25 MB，具体上限可由企业管理员调整。

“上传文档密级”只用于新上传的文件。要查看某一级别的已有文档，请用“筛选已有文档密级”；旁边会显示筛选后的数量及当前账号可见总数。切换上传密级不会改动已有文档，也不会改变总数。

## 查找和打开

在文件名搜索框输入名称，可缩小列表；查文件正文请到智能助手提问。点“打开”预览，点“下载”保存原文件。预览可能只显示部分内容，下载也要符合当前账号的文件权限。手机端点“打开”后可在页内翻阅；点“下载”后，保存位置由手机浏览器决定。

## 比较多份文件

1. 在列表中勾选文件，点“基于选中 N 份文件提问”。若按钮不可用，检查是否有文件仍在处理。
2. 到智能助手核对已选文档，写清想比较的内容。例如：“比较这两份制度的适用日期和提交期限，分别附上原文来源。”
3. 发送后打开引用，确认每项结论对应哪份文件。

只查一份时，可点该文件的“基于此文件提问”。列表中的“全选”只选择当前筛选结果。下一轮提问会继续使用当前选中的参考文档；要换范围，在助手中移除或清空参考文档。文件名相同不保证内容相同，更新文件后请查看版本和处理结果。

**遇到问题**：扫描 PDF 若显示正文为空，换用可选中文字的 PDF 或 Word 文件；仍无法处理时，请管理员检查文字识别服务。选了多份文件却不能提问，先移除未显示“已可检索”的文件。

管理员删除文件时会收到确认提示。删除后无法从列表恢复；批量删除请看逐项结果。
