# 知识库文档

“上传文档密级”仅设置下一次上传，不改变已有文件和数量。“筛选已有文档密级”用于筛选当前账号可见列表；标题显示筛选数，底部显示筛选数与可见总数。每个文件单独标注密级和已登记部门范围；一级也不意味着所有人都可访问。

## 上传与处理结果

1. 进入资料中心的“知识库”标签。
2. 选择本次上传密级；部门由服务端按账号登记。
3. 点击上传区选文件或拖入文件，支持多选。格式：PDF、DOCX、TXT、Markdown、XLSX、CSV。
4. 查看每个文件的进度和回执；传输100%后可能仍在解析、入库。
5. 等待列表显示“已可检索”，再基于文件提问。

文档默认单文件上限25 MiB，部署方可调整。整批上传逐项处理，一个成功不代表全部成功。“清除已完成”只清上传队列显示，不删文件。

PDF回执可能展示扫描页、OCR和文字来源。OCR依赖部署环境；提取失败时换文字版PDF或Word，或联系管理员。刷新后不保证保留本次上传回执里的全部提取读数。

## 搜索、预览与原文件

文件名搜索框过滤当前列表，不是全文搜索。查内容请去智能助手。

“打开”查看预览；“下载”取原文件，仍受下载权限限制。预览可能截断或受格式限制，不能用预览长度代替完整资料范围。关联区域可打开已登记且有权访问的相关文件。

## 同时参考多份文件

1. 勾选要比较或查询的文件；“全选”只作用于当前过滤后的列表。
2. 点击“基于选中 N 份文件提问”。未全部可检索时按钮不可用，等待处理或移除未就绪文件。
3. 在智能助手右侧核对全部参考文档，编辑问题后发送。
4. 例如：“分别说明这两份制度的生效日期、提交期限和审批门槛，并标明来源。”
5. 打开回答引用的原文核对。追问默认沿用这组文档；可逐份移除或清空参考文档。

单份文件也可点击行内“基于此文件提问”。指定范围和实际引用分开显示：选中不等于整份文件已阅读，检索未命中或上下文不足时不会保证所有内容都被使用。跨文件精确计算请先整理为经营数据表。

## 更新与删除

知识库同名内容更新有版本语义，内容未变可能沿用索引；检查回执和版本状态，不能只看文件名。经营数据同名上传规则不同。

管理员可单行或批量删除，先确认再执行。删除不可恢复；批量可能部分失败，查看逐项结果，不重复删除不相关文件。
