## 准备和上传

支持XLSX和CSV，旧XLS应另存为XLSX。使用明确列名、统一日期、明确单位；先检查空值、重复、混合单位，避免把总计行再次作为明细求和。

1. 进入资料中心“经营数据”，点击“上传数据”。
2. 等待解析，选择文件。
3. 检查数据画像的行数、列数、字段类型、缺失等情况。
4. 点击“打开”抽查数据，确认可见范围。

经营数据同名上传会拒绝覆盖，应给新版明确的新文件名。数据登记和知识库索引入库分别返回结果，数据上传成功不保证已经可检索。

上传前可选“上传数据密级”，默认2级沿用原数据上传设置；选择只影响下一次上传，不修改已有文件。经营数据和知识库中的同一份新表采用所选等级。文件列表标注密级与部门范围，可用“筛选已有数据密级”查看相应等级；数量显示筛选数 / 当前账号可见总数。角色、部门、所有者和行权限仍由服务端判断，筛选不授予访问权限。

## 联合制度核查

先选择经营表并点击“分析这份数据”，再到知识库勾选适用制度，点击“基于所选文件提问”。右侧应同时列出数据表和参考文档。问题写清日期、状态、汇总字段及核查目的，例如：“2026-10-01至2026-10-10，仅统计已批准或已支付，按部门汇总金额和记录数，并核查所选制度；展示计算事实、原文依据和缺失材料。”状态名称须使用表中的实际取值。

核对授权可见行、合计、记录数、单位和制度适用日期，再追问或生成本次报告。只有一个可见部门时不能据此进行部门间比较；没有历史、预算或业务材料时不能推断增长或确定原因。

## 画像、预览和权限

画像可展示适用的最小值、最大值、均值和唯一值数量。预览可能只显示部分行；截断和权限隐藏都不能当成原表为空。下载需权限，管理员删除所选数据前需确认。

当前分析一次指定一份文件。多工作表问题请明确工作表名称和统计对象，复杂结构应先整理为清晰分析表；不承诺自动合并多个文件或任意跨表联查。

## 开始分析

选择文件后点击“分析这份数据”，核对带入的文件并补充问题；也可使用模板：

| 模板 | 要看什么 | 必备条件 |
|---|---|---|
| 经营概览 | 总量、结构、主要发现 | 指标适合汇总，单位一致 |
| 分组对比 | 部门、项目、产品差异 | 有分组字段 |
| 趋势分析 | 期间变化 | 日期与可比指标 |
| 费用与预算 | 实际、预算、差额、偏差率 | 有预算；没有时不能编造 |
| 异常核查 | 缺失、重复、明显异常 | 判断方法明确，推测与事实分开 |
| 数据质量 | 行列、缺失、重复、可用性 | 核对授权可见范围 |

模板只准备可编辑问题，不自动发送。填写期间、筛选条件、指标和单位后发送。完成后核对实际用表，再去 [成果交付](../delivery/artifacts.md)。
