# 上传和分析经营表

[返回资料与分析](README.md) · [智能助手提问](assistant.md)

## 上传一份表格

**入口**：电脑端进入“资料中心”→“经营数据”；手机端点底部“资料”→“经营数据”。准备 XLSX 或 CSV 文件，先检查列名、日期、金额单位和重复行。旧 XLS 文件请另存为 XLSX。

1. 在“上传数据密级”选择这次表格的级别，再点“上传数据”选文件。
2. 等处理完成，查看行数、列数、字段类型和缺失情况。
3. 点“打开”抽查记录和单位，确认上传的是目标表格。

**完成后**：列表出现这份表格，文件概览显示行列数和字段情况。上传成功与可用于分析是两个阶段；若页面还显示处理中，等处理完成再提问。

上传密级默认 1 级，只影响这次上传的表格。“筛选已有数据密级”用于筛选现有列表，不会修改文件。首次上传遇到同名资料会被拒绝；要更新已有表格，请使用下面的“更新版本”。

页面预览可能只展示部分记录。需要确认原表全貌时，请打开或下载有权访问的文件。你看到的记录受账号权限限制。

## 更新已有表格

1. 选中要更新的经营数据，在文件概览点“更新版本”。选择与原表相同格式的 CSV 或 XLSX 新文件。
2. 核对目标文件、当前版本、新文件名和原权限，再点“确认更新”。选择文件后也可以取消；取消不会上传。
3. 等页面显示新版本及行数、字段变化，再检查预览。新文件可以有不同文件名，资料列表仍保留原来的名称；文件负责人、部门范围和密级沿用原设置。

重复提交完全相同的内容不会新增版本。若有人先更新了资料，页面会要求刷新列表后重新核对。索引或登记失败时，上一版本继续可用；若网络中断、结果无法确认，请先刷新列表查看当前版本，避免反复提交。

旧任务、计算和报告保留生成时的版本。更新后，请明确选择新版发起新分析；原任务不会悄悄换成新数据。更新前请检查相关提醒规则：“固定当前版本”继续使用绑定版本，“跟随最新版”在下次巡检使用新版本，并保留每次依据。已有规则沿用原来的跟随方式；设置方法见[异常提醒](../tasks/alerts.md)。

## 提出分析问题

在目标表格上点“分析这份数据”，确认智能助手中带入了正确文件，再写问题。电脑端也可直接进入“智能助手”；手机端可点底部“问答”。可以先选“经营概览”“分组对比”“趋势分析”等模板；模板只填入文字，需要你检查后发送。

问题尽量写全：**统计对象、期间、筛选条件、指标、单位和想看的结果**。例如：“统计 2026 年 1—6 月已批准的报销记录，按部门汇总金额和笔数，展示月度趋势，金额单位沿用原表。”状态值要与表格中的实际取值一致。

**完成后**：回答应说明本次使用的表格和统计范围；有图表时，核对图上的单位和分组是否与问题一致。当前一次分析选择一份经营数据文件。若表里有多个工作表，请指明工作表和统计对象；多份表不会自动合并计算。趋势需要日期列，预算比较需要预算数据；缺少所需字段时，先补充数据或缩小问题。

复杂查询的范围卡会标明“输入期间”“输入记录数”和“输入字段单位”。这些说明查询前使用了哪些数据；进一步筛选、计数或计算后的结果，以回答中的查询结果为准。例如，输入有6条记录，不代表筛选后仍有6条；金额字段以元计量，也不代表记录数的单位是元。

## 按原条件分析新版

打开原任务，在“分析范围”找到已完成的计算，点“按这次条件再分析”。系统先按你当前权限读取同名资料的当前版本，核对已记录字段；字段被删除或单位随列名改变时，会说明无法直接复用，不会猜测替代列。

核对通过后，会新建一份待发送问题，保留原期间和筛选条件。检查当前文件和问题，按需要修改，再发送；点入口本身不会运行分析或生成文件。制度文档需要重新选择。新结果和原任务分别保存，旧答案不会充当新版结果。

输入框已有内容、任务正在处理或还有待确认动作时，请先处理当前内容。旧计算缺少可核对字段时，请参照原问题重新填写。若准备后资料再次更新，发送会被拒绝；先检查新版字段，再发起分析。当前仅支持同名经营资料的版本复用，没有团队共享模板或自动定时执行。

## 同时核查制度

需要对照制度时，先选经营表，再到“知识文档”选适用文件并点“基于选中 N 份文件提问”。回到智能助手，确认右侧同时列出了数据表和参考文档，再提出核查问题。

回答后分别检查计算结果与制度引用。金额符合某项标准，只说明这项比较的结果；缺少凭证、日期或适用条件时，还需要人工核实。分析结果的保存与下载见 [图表与报告](../delivery/artifacts.md)。
