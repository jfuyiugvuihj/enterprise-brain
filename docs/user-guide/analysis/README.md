# 资料与分析

[返回总目录](../README.md)

| 功能页面 | 用途 | 完成后拿到什么 |
|---|---|---|
| [知识库文档](documents.md) | 上传制度、手册，定位原文，单份或多份提问 | 解析和索引回执、带来源的答复 |
| [经营数据](datasets.md) | 上传表格，检查字段，准备统计分析 | 数据画像、实际计算结果和图表 |
| [智能助手](assistant.md) | 提问、模板分析、追问、核对依据 | 回答、图表、报告入口 |

查询制度用知识库；精确求和、分组、趋势用经营数据。表格进入知识库后，片段检索仍不能代替整表计算。资料准备好后带入智能助手，核对对象与范围再发送。
