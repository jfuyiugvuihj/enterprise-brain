# 查资料与分析数据

[返回使用帮助](../README.md)

第一次使用，可按“选资料 → 提问 → 核对依据 → 保存成果”的顺序操作。

1. **查制度、合同或手册**：从 [上传和查询文档](documents.md) 选文件。文件显示“已可检索”后，在 [智能助手](assistant.md) 提问，并打开回答引用的原文。
2. **统计金额或看趋势**：从 [上传和分析经营表](datasets.md) 选表格。确认列名、期间和单位后，到智能助手提出分析问题。
3. **保存结果**：确认回答符合原文件后，可 [生成并下载报告](../delivery/artifacts.md)。

一个问题也可以同时使用表格和制度：表格提供计算数据，文档提供制度依据。发送前，在助手中确认两类资料都选对。已有文件时，可直接从列表点“基于此文件提问”或“分析这份数据”。
