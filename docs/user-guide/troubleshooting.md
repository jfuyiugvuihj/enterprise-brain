# 遇到问题怎么办

[返回使用帮助](README.md)

先按页面提示重试。若仍无法解决，按下面的情况处理。

## 登录和权限

**登录过期或反复退出**：重新登录。反复出现时，把发生时间告诉管理员。

**看不到文件，或打开、下载被拒绝**：在“我的账号”核对角色和部门，再请管理员检查文件密级和授权。

**两人分析同一张表，合计不同**：对照各自可见记录、期间、筛选条件和单位。

## 上传和提问

**文件已上传，却不能用于提问**：到“资料中心”→“知识文档”看是否显示“已可检索”。仍在处理就等待；处理失败则查看提示。

**扫描 PDF 提取不到文字**：换成可选中文字的 PDF 或 Word 文件；必要时请管理员检查文字识别服务。

**多选文档后提问按钮不可用**：找出尚未处理完成的文件，等待完成或先移除。

**表格预览只显示少量行**：预览可能只展示部分记录。检查页面范围，必要时打开或下载授权文件。

**回答没有引用某份文件**：在问题中点明要比较的文件，再核对引用并打开原文。

## 待办与成果

**批准操作后没有成果**：回原任务查看实际执行状态和失败提示。批准只表示允许继续。

**提交确认时网络中断**：点“重新读取决定”，核对已保存的选择，再决定是否重试。

**异常巡检失败**：查看提示，核对表格、指标列、期间和访问权限后重查。

**PDF 预览或下载失败**：刷新成果列表，核对权限和文件状态；仍失败时告诉管理员文件名和发生时间。

**报告能打开但内容有误**：回到原表和分析，修正数字、单位或引用后重新生成。

联系管理员时，提供**页面名称、发生时间、文件名、操作步骤和错误提示**。不要发送密码或未经授权的资料。
