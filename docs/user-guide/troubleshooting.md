# 常见问题与使用边界

[返回总目录](README.md)

| 现象 | 先检查什么 | 下一步 |
|---|---|---|
| 登录过期 | 提示是否明确失效 | 重新登录 |
| 资料不可见、操作拒绝 | 角色、部门、密级、资源范围 | 管理员核对授权 |
| 上传失败 | 真实文件格式、当前大小上限 | 换支持格式、拆分或联系管理员 |
| 数据同名冲突 | 已有同名数据集 | 使用明确新版文件名 |
| 文件存在但不能提问 | 解析和索引状态 | 等待完成或处理提取错误 |
| 扫描PDF没有文字 | OCR回执 | 换文字版或检查部署OCR |
| 勾选多份却不能开始 | 是否全部可检索 | 等待或移除未就绪项 |
| 回答未引用每份文件 | 实际引用、内容相关性、上下文限制 | 明确逐份比较，并回原文核对 |
| 表格预览少行 | 截断、行级权限 | 核对实际可见范围 |
| 两账号合计不同 | 各自可见行、期间、筛选 | 统一比较口径 |
| 模型或检索不可用 | 故障提示、发生时间 | 待恢复或联系管理员 |
| 批准后没有成果 | 后续执行状态 | 看失败原因，批准不等于成功 |
| 确认请求网络失败 | 服务端决定是否仍待确认 | 保留确认卡，结果未知时重新读取，不重复猜测执行结果 |
| 巡检提示核查失败 | 指标列、工作表、期间与授权范围 | 修正输入后重查，不能把失败当作异常恢复 |
| 提醒已恢复但仍显示关闭 | 恢复时间与人工处置记录 | 两种状态分别保留，不需要为了恢复删除历史 |
| 报告无法下载 | 权限、文件存在、有效期 | 管理员核查资源 |
| 文件能开但内容错 | 原表、原分析、单位、来源 | 修正后重新生成 |
| 历史记录缺字段 | 是否当时保存过 | 不补造缺失信息 |
| 系统数字未知 | 是否取得读数 | 不按零值解释 |

报问题时提供页面、时间、文件名、复现步骤及可用运行编号；不要发送密码、令牌或无权传播的资料。

## 当前边界

- 多文档知识问答可指定一组参考文档，但检索不是整份逐字阅读，不承诺所有片段进入上下文。
- 经营数据分析一次指定一份文件，不承诺多文件自动合并或任意跨表联查。
- OCR依赖部署环境；扫描件需检查提取结果。
- 费用自查不是正式报销审批或付款系统；图谱登记也不是事实认证。
- 页面不提供通用模型管理、任意系统配置或已有账号角色编辑。
- 回答、数字、图表和报告应按实际文件核对；历史冒烟或评测通过不能证明所有行业和图型的内容质量。
- 客户真实权限、资料和真人持续试用仍要在交付阶段核验，合成演示不能代替。
- 390px窄屏导航支持横向滚动，文字保持独立；这不等于已在所有真实手机上验收。
