# 处理待确认操作

[返回异常与待办](README.md)

## 决定是否继续执行

**入口**：电脑端从侧栏进入“待办事项”；手机端点“更多”后进入“待办事项”。智能助手中的确认卡也会指向同一项操作。

1. 打开“待办事项”，在上方列表选中待确认操作。
2. 阅读要执行的动作及影响；需要更多背景时，回原对话查看。
3. 选择“批准”或“驳回”，等待页面更新。
4. 返回任务查看结果：已拒绝、已取消、执行失败和执行成功各有不同含义。

**完成后**：待确认列表中的该项不再等待你的选择，原任务显示最终执行状态。若执行失败，按页面提示处理后再决定是否重试。

页面会保留最近一次操作的回执，列表刷新后仍可查看。点“关闭回执”只收起提示，不会撤销决定。换浏览器登录后，可从“待办事项”找到仍待确认的操作，再回到原对话核对分析范围。

“批准”表示允许系统继续，不保证后续动作成功。提交时网络中断，页面会尝试读取服务端决定；“确认已记录”仍需回原对话查看实际成果。若结果仍未知，在待办页点“重新读取”，或在聊天确认卡点“重新读取决定”；确认仍在等待后再操作，避免重复提交。执行前系统还会重新检查你当时的权限。

中断聊天不会自动拒绝待确认操作；已完成的动作也不会因中断而撤销。

## 对照费用标准自查

页面下方的“费用自查”用于对照知识库中的报销标准。把示例金额、费用类型和部门改成实际情况，点“重新自查”，再打开标准来源查看适用条件。

找不到标准或缺少材料时，页面无法给出完整判断。金额未超过某项标准，只说明这项比较的结果；费用自查不会创建正式审批单，也不会付款。
