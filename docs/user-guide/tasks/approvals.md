## 实际待确认操作

上方列表展示任务中真实挂起的确认操作，与智能助手确认卡对应。阅读操作内容和影响 → 必要时返回原对话核查 → 批准或驳回 → 检查后续状态与成果。

批准只表示允许执行；批准后失败仍是失败，不能把确认回执当成果回执。没有待确认操作时显示空列表。中断聊天不会自动拒绝该操作。

提交决定时保留确认卡，避免重复点击。网络失败后界面读取服务端决定；仍待确认时可重试，结果未知时先“重新读取决定”。只有服务端记录拒绝才显示已拒绝。中断会请求取消后续处理，不撤销已完成动作，取消标记也可能阻止下一轮续跑。

执行时会重新校验当前账号权限；更换部门或失去权限后，旧确认不能让任务继续访问原资料。拒绝、取消、执行失败与成功是不同结果。

## 费用自查

下方按知识库报销标准检查费用参数：把演示初始金额和类型改成实际值，核对部门，点击“重新自查”，检查标准来源、超出金额、比例和建议。

标准来自知识库，不能在此随意替换。未找到标准时无法得出合规结论。费用自查不创建正式审批单、不改变报销单、不付款；与上方真实操作确认是两个功能。

金额未超所给标准只说明这项比较通过，不能说明材料全面合规。审批人金额分档不作为报销上限；多项金额标准冲突且适用条件不明时，需要补充条件后判断。
