# 查看和处理异常提醒

[返回异常与待办](README.md) · [通知中心](notifications.md)

## 从提醒开始核查

**入口**：电脑端从侧栏进入“异常提醒”；手机端点“更多”后进入“异常提醒”。只有具备相应权限的账号才会看到处理操作。

1. 打开“异常提醒”，选一条需要处理的记录。
2. 展开“计算依据”，查看文件及版本、统计期间、筛选条件、单位、记录数、当前值与阈值。
3. 点“继续分析这条异常”，在智能助手中补充问题并发送。系统会带入这条提醒的数据范围。
4. 对照原始记录检查分析结果，再从“返回这条异常提醒”回到原记录。
5. 按实际进展确认、指派负责人或关闭提醒。

**完成后**：回到这条提醒，应能看到更新后的状态、负责人或处理记录。若生成了报告，可从提醒详情进入对应成果。

“确认”表示接收提醒，“关闭”表示人工处置完成。数据恢复正常会另行记录，两种状态可能同时存在。主要贡献分组是排查线索，需要进一步核实原因；没有历史数据的提醒，只能说明当前值达到了设定阈值。

同一对象、同一统计窗口持续达到阈值时，原提醒会更新并保留处理记录。新数据到达后可重新查看计算结果；从提醒生成的报告可在提醒详情和成果中心找到。

## 设置和检查规则

有管理权限时，填写规则名称、表格中的指标列名、比较方式和阈值，点“新增规则”。需要缩小范围时，再设置期间、筛选条件或分组。阈值单位应与指标一致；金额可求和，比例、单价和编号通常不能直接相加。

新建规则默认“固定当前版本”。选择一份有权访问的经营数据，核对页面显示的版本，再保存。资料以后更新，这条规则仍检查绑定的版本；从提醒继续分析和生成报告，也沿用该次依据。

需要每次巡检都检查新数据时，明确选择“跟随最新版”。可以指定一份资料，也可留空检查全部授权可见资料。已有规则保留原来的跟随方式，列表会标明“已有规则”。新数据到达后不会自动改变固定规则；需要检查新版时，请针对新版另建规则。

保存前资料版本变化时，先刷新文件列表，核对新版后再保存。固定版本文件缺失、内容与登记不符，或负责人当前权限不足时，巡检会提示未完成判断，不会换成其他版本或把失败记成恢复。旧版明细和报告仍受当前权限控制。

规则建好后，点“立即巡检”检查全部规则，或点“巡检本规则”。打开页面本身不会触发检查。**巡检失败时**查看提示，核对数据文件、列名和权限，再重试；检查失败不能视为指标恢复。是否安排定时巡检，请向管理员确认。

列表为空时，先检查是否有规则、数据是否已处理完成，以及当前账号能否访问相关记录。
