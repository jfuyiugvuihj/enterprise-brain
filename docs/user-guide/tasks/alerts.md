## 登记规则与巡检

有告警管理权限的账号填写规则名称、准确指标列名、比较方式和阈值，点击“新增规则”。可指定经营表、期间与筛选条件、贡献维度。当前规则比较授权记录中的指标合计，不支持把比例、单价或编号合计；列名、阈值和数值单位必须对应。

进入页面不会自动巡检。点击“立即巡检”检查当前可见经营数据，或在规则行点击“巡检本规则”。命中才产生提醒；读取失败或缺少指标显示核查失败，不能据此判断异常已恢复。是否定时巡检由部署配置决定。删除规则需确认，不会自动关闭历史告警。

展开计算依据，核对文件版本、期间、筛选、单位、记录数、当前值、阈值与贡献明细。没有历史或预算比较时仅是阈值提醒，不是增长证明；贡献维度也不是确定原因。

## 处置闭环

1. 阅读告警指标、阈值、发生情况和状态。
2. 点“继续分析这条异常”，带着原文件、版本和口径到智能助手，补充核查问题后发送。
3. 检查数据和依据，把可能原因与已确认事实分开。
4. 从右侧“返回这条异常提醒”回到原记录。
5. 根据实际情况“确认”“指派”负责人或“关闭”。

确认表示已接收，关闭表示完成处置，不意味着原数据自动修正。空告警列表也不能证明企业没有风险：没有规则、缺少数据或无法读取都可能导致没有告警。

同一对象和窗口持续命中只更新原提醒，保留负责人与处置状态。新数据重算保留观测历史；低于阈值后单独标记恢复，人工关闭仍单独显示。恢复后再次命中产生新提醒。更新后的提醒不能用旧版本继续分析，旧成果保留生成时依据。

分析生成的成果会出现在提醒详情中；成果中心也可返回原提醒。报告下载仍按当前权限检查，批准执行不能代替资源授权。
