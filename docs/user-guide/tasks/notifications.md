# 查看和清理通知

[返回异常与待办](README.md)

**入口**：电脑端点页面顶部的通知按钮；手机端点底部“消息”。打开后可查看与你有关的异常和待确认操作。点通知中的链接进入对应页面；只读消息不会自动处理原事项。

- 点“标为已读”记录已看过一条；点“全部标为已读”可一起处理当前账号可读取的通知。
- 点“划掉”移除一条；点“全部划掉”时，先看页面给出的数量，再确认。此操作会移除当前账号可见的已读和未读通知。
- 若通知数量未能完整读取，页面会阻止“全部划掉”。刷新后再核对数量。

**完成后**：被划掉的通知不再出现在当前账号的通知列表中；标为已读的通知仍可继续打开。

清理通知不会关闭异常、批准操作或删除成果。需要继续办事时，从“异常提醒”或“待办事项”进入原记录。
