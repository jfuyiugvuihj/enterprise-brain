本手册覆盖公司三大核心产品的技术架构、部署方案、API接口、运维监控及故障排查。

================================================================================
第一章  智慧协同办公平台 MingYuan Office（MYO）
================================================================================

1.1 产品概述
-----------
MYO 是企业级协同办公平台，集成即时通讯、视频会议、文档协作、任务管理、审批流程五大模块。采用微服务架构，支持 SaaS 云端部署和私有化部署两种模式。

1.2 技术架构
-----------
1.2.1 后端技术栈
- 语言：Java 17（Spring Boot 3.2 + Spring Cloud 2023）
- 消息队列：Apache Pulsar 3.2（替代 RabbitMQ 以实现更好的水平扩展）
- 数据库：PostgreSQL 16（主库） + Redis 7.2 集群（缓存与 Session）
- 搜索引擎：Elasticsearch 8.12（全文检索 + 日志分析）
- 对象存储：MinIO 集群（文档/图片/附件存储）
- 容器编排：Kubernetes 1.29（生产环境使用 AWS EKS 或自建 K8s）

1.2.2 前端技术栈
- 框架：React 18 + TypeScript 5.4
- 状态管理：Zustand + React Query
- UI 组件：自研 MYO Design System（基于 Radix UI）
- 实时通信：WebSocket（消息推送） + WebRTC（音视频通话）
- 构建工具：Vite 5 + pnpm workspace monorepo

1.2.3 微服务拆分（共 18 个服务）
核心服务：user-service（用户认证/OAuth2.0+JWT）、message-service（消息收发/已读回执）、doc-service（文档协同编辑/OT算法）、
meeting-service（音视频会议/SFU架构）、workflow-service（审批流程引擎/Activiti 7）、notification-service（多通道推送/邮件+短信+App Push）。

1.3 部署方案
-----------
1.3.1 SaaS 标准版（AWS）
- 3 个 EKS 工作节点（m6i.4xlarge），按可用区分布
- RDS PostgreSQL Multi-AZ 主备
- ElastiCache Redis 3 分片集群
- CloudFront CDN 加速前端静态资源
- 日均承载 50000 并发用户，消息延迟 < 200ms（P99）

1.3.2 私有化部署（客户机房）
- 最低配置：3 台物理服务器（16 核 64G 内存 + 1TB SSD）
- Kubernetes 集群（RKE2 发行版）
- 内置 PostgreSQL + Redis + MinIO（无需外部依赖）
- VPN/专线接入客户内网
- 离线安装包大小约 8GB（含所有 Docker 镜像 + 初始化脚本）

1.4 关键 API
-----------
POST /api/v1/message/send         发送消息
GET  /api/v1/doc/{id}/collaborate 获取协作文档
POST /api/v1/workflow/approve      提交审批
GET  /api/v1/meeting/join/{roomId} 加入视频会议

第二章  智能数据分析平台 MingYuan BI（MYBI）
================================================================================

2.1 产品概述
-----------
MYBI 是企业级 BI 分析平台，支持多数据源接入、可视化报表、自助式分析、数据预警。基于 Apache Superset 深度定制，增加了 AI 辅助分析和自然语言查询功能。

2.2 技术架构
-----------
2.2.1 数据处理链路
数据源（MySQL/PostgreSQL/Oracle/SQL Server/Hive/ClickHouse）→ Apache DolphinScheduler 定时调度 → Apache Spark 3.5 ETL 处理 → Apache Doris 2.1（MPP 分析引擎）→ 前端可视化。

2.2.2 AI 分析引擎
- NL2SQL：基于通义千问 72B 微调模型，自然语言→SQL 准确率 89.7%（内部测试集）
- 智能图表推荐：基于数据特征（维度数/基数/分布）自动推荐柱状图/折线图/饼图/热力图
- 异常检测：3-sigma + LSTM 时序预测，自动标注数据异常点
- 大模型网关：统一管理 OpenAI/通义千问/文心一言等多模型调用

2.2.3 可视化
- 图表库：ECharts 5.5 + D3.js v7
- 支持图表：柱状图、折线图、饼图、散点图、热力图、漏斗图、雷达图、桑基图、甘特图、词云
- 自定义大屏：拖拽式布局，支持 30+ 组件，导出 PDF/PNG
- 移动端适配：自适应布局，支持微信/钉钉小程序嵌入

2.3 性能指标
-----------
- 10 亿行数据查询响应时间 < 3 秒（Doris 分区剪枝 + 物化视图）
- 100 并发用户同时查询不降速（连接池 + 查询队列）
- 数据导入吞吐量：500 万行/秒（Spark 并行写入 Doris）
- 图表渲染性能：首屏 < 1.5 秒（ECharts 增量渲染 + 虚拟滚动）

第三章  企业智能运维平台 MingYuan Ops（MYOps）
================================================================================

3.1 产品概述
-----------
MYOps 是面向 DevOps 团队的智能运维平台，覆盖 CMDB（配置管理数据库）、监控告警、日志分析、自动化部署、成本优化五大场景。

3.2 技术架构
-----------
3.2.1 监控体系
- 指标采集：Prometheus + Node Exporter + 自定义 Exporter（Java Agent 方式注入）
- 日志采集：Filebeat → Kafka → Logstash → Elasticsearch（ELK Stack + Kafka 缓冲）
- 链路追踪：OpenTelemetry + Jaeger（支持 Java/Go/Python/Node.js 多语言）
- 告警引擎：Prometheus Alertmanager → 自定义告警路由（飞书/钉钉/企业微信/短信/PagerDuty）

3.2.2 自动化运维
- CI/CD：GitLab CI + ArgoCD（GitOps 模式），支持金丝雀发布和蓝绿部署
- 基础设施即代码：Terraform + Ansible，多云统一管理（AWS + 阿里云 + 私有云）
- 成本分析：AWS Cost Explorer + 阿里云费用中心的统一成本 Dashboard
- 健康检查：每 30 秒对所有服务进行 TCP + HTTP 探活

3.2.3 安全运维
- 漏洞扫描：Trivy 每日扫描所有容器镜像
- 配置审计：Open Policy Agent (OPA) 策略引擎
- 密钥管理：HashiCorp Vault（数据库密码/API Key/证书轮转）

3.3 运维 SLA
-----------
- 系统可用性：99.95%（年度允许宕机时间 < 4.38 小时）
- 告警响应：P0 故障 5 分钟内响应，P1 故障 15 分钟内响应
- 故障恢复：P0 故障 30 分钟内恢复，P1 故障 2 小时内恢复
- 数据备份：核心业务数据 RPO（恢复点目标） < 1 小时，RTO（恢复时间目标） < 4 小时
- 灾备切换：主数据中心故障后 15 分钟内自动切换至灾备中心
