# MYBI 技术白皮书

## 1. 概述

MYBI 是一款面向企业级数据分析场景的智能商业智能产品，旨在通过高性能数据处理引擎与先进AI能力的深度融合，为用户提供从数据接入、处理、分析到可视化的全链路解决方案。本白皮书详细阐述MYBI的技术架构、核心能力与性能指标，帮助技术决策者理解其设计理念与工程实践。

## 2. 数据链路架构

MYBI 的数据处理链路采用分层解耦设计，确保端到端的高吞吐与低延迟。

### 2.1 多源接入层
支持关系型数据库（MySQL、PostgreSQL、Oracle）、日志文件（Fluentd、Logstash）、消息队列（Kafka、RocketMQ）及API接口等20余种数据源。通过连接器插件化架构，实现数据源动态扩展，并内置断点续传与数据校验机制，保障数据完整性。

### 2.2 任务调度层
采用 Apache DolphinScheduler 作为工作流调度引擎。基于DAG（有向无环图）模型编排ETL任务，支持定时、依赖触发及手动执行三种模式。系统提供可视化任务监控面板，实时追踪各节点执行状态，异常时自动告警并触发重试策略（默认3次，间隔30秒）。

### 2.3 数据处理层
核心ETL引擎基于 Apache Spark 构建，运行于YARN集群模式，动态资源分配支持弹性伸缩。典型处理流程包括：
- 数据清洗：去重（基于主键或MD5指纹）、空值填充（均值/中位数/众数策略）、格式标准化。
- 数据转换：类型映射、维度退化、聚合计算（如滑动窗口SUM、AVG）。
- 数据加载：采用批量写入（Batch Load）与流式写入（Stream Load）双模式，适配不同实时性需求。

### 2.4 存储与查询层
选用 Apache Doris 作为MPP（大规模并行处理）分析引擎。Doris的列式存储与向量化执行引擎为OLAP场景优化，支持：
- 分区与分桶：按时间（日/月）分区，按常用维度（如用户ID）哈希分桶，减少数据扫描范围。
- 物化视图：预计算高频聚合结果，查询响应时间降低80%以上。
- 高并发查询：通过查询队列与资源组隔离，保障多用户场景下的稳定性。

### 2.5 可视化层
前端基于 ECharts 实现图表渲染，支持折线图、柱状图、散点图、热力图等50余种图表类型。通过WebSocket推送实时数据更新，渲染帧率稳定在60fps。用户可通过拖拽式操作完成维度、度量的自由组合，无需编写SQL。

## 3. AI能力体系

MYBI 内置四大AI模块，将机器学习与自然语言处理能力嵌入数据分析全流程。

### 3.1 NL2SQL（自然语言转SQL）
基于通义千问72B大模型进行领域微调，模型参数规模72B，训练数据包含10万+企业级SQL查询样本及对应自然语言描述。经测试，NL2SQL准确率达到89.7%（基于SPIDER基准测试扩展版）。用户输入“上月各区域销售额排名”，系统自动生成符合Doris语法的SQL语句，并返回图表结果。

### 3.2 智能图表推荐
系统自动分析查询结果的数据特征（维度数量、度量类型、分布形态），基于决策树模型（XGBoost训练，准确率92.3%）推荐最合适的图表类型。例如，时间序列数据优先推荐折线图，地理维度数据优先推荐地图热力图。

### 3.3 异常检测
采用3-sigma与LSTM（长短期记忆网络）双模型融合策略：
- **3-sigma**：适用于正态分布数据，快速识别超出均值±3倍标准差的值。
- **LSTM**：基于历史12个时间步的数据预测当前值，计算残差并设定动态阈值（95%置信区间）。  
系统综合两种模型结果，输出异常评分（0-100），评分>80时触发告警。在金融交易场景测试中，召回率达94.1%，误报率低至2.3%。

### 3.4 大模型网关
统一管理多个大语言模型API，支持OpenAI GPT-4、通义千问、文心一言等主流模型。提供以下功能：
- **负载均衡**：根据各模型响应时间与成本自动路由请求。
- **结果缓存**：对相同Prompt的查询结果进行哈希缓存，减少重复调用。
- **安全审计**：拦截包含敏感词（如身份证号、银行卡号）的请求，并记录日志。

## 4. 性能指标

MYBI 在标准测试环境（16核CPU、64GB内存、SSD存储、千兆网络）下达到以下性能：

### 4.1 查询性能
- **10亿行数据聚合查询**：在Doris中执行GROUP BY + SUM/AVG操作，95%的查询响应时间低于3秒。
- **100并发查询**：在持续100个并发请求下，系统吞吐量稳定在5000 QPS，查询平均延迟不超过1.2秒，无显著降速。

### 4.2 数据导入性能
- **批量导入**：通过Spark批量写入500万行数据（每行50个字段），采用HTTP Stream Load方式，平均耗时4.2秒，即约119万行/秒。
- **实时导入**：Kafka数据流式写入，单分区吞吐量达1.2万条/秒，端到端延迟（数据产生到可查询）小于5秒。

## 5. 部署与运维

MYBI 支持私有化部署（基于Kubernetes容器化）与SaaS云服务两种模式。运维层面提供：
- **自动扩缩容**：根据CPU/内存利用率，自动调整Spark与Doris的计算节点数。
- **数据备份**：每日全量备份 + 每小时增量备份，支持任意时间点恢复（PITR）。
- **审计日志**：记录所有数据访问与操作行为，满足SOX、GDPR等合规要求。

## 6. 结语

MYBI 通过“高吞吐数据管道+AI原生分析引擎”的双轮驱动，解决了传统BI产品在数据规模与智能分析能力上的瓶颈。其89.7%的NL2SQL准确率、3秒级十亿行查询性能以及秒级数据导入能力，已在金融、电商、物联网等领域得到验证。未来，MYBI将持续优化大模型推理效率，并探索多模态数据分析（文本+图像）的融合能力。
