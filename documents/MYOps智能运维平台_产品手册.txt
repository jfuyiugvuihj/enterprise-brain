# MYOps 产品手册

## 产品概述

MYOps 是面向现代云原生架构的一站式运维平台，旨在通过五大核心场景解决企业在配置管理、监控告警、日志分析、自动化部署及多云成本优化中的复杂问题。本手册详细说明各场景的功能、架构及操作指南。

---

## 场景一：配置管理（CMDB）

### 核心能力
- **自动发现**：基于 SSH、WinRM 及云厂商 API（AWS、阿里云）自动扫描并采集服务器、容器、网络设备等资源信息，支持定时增量同步。
- **关系图谱**：通过图数据库（Neo4j）构建资产间依赖关系，如“应用 A 依赖数据库 B，部署于主机 C”，支持可视化拓扑图与链路追踪。
- **配置变更审计**：记录所有配置修改历史，支持回滚至任意历史版本，并关联告警事件。

### 操作流程
1. 配置自动发现规则（如 IP 段、云账号凭证）。
2. 启动扫描任务，资产自动入库并生成关系图谱。
3. 在 CMDB 页面查看拓扑图，支持按标签、类型筛选。

---

## 场景二：监控告警

### 核心能力
- **多数据源接入**：集成 Prometheus 采集指标数据，支持自定义 Exporter（如 Java、Python 应用）暴露业务指标。
- **多通道告警**：通过 Alertmanager 将告警推送至飞书、钉钉、企业微信、短信及 PagerDuty，支持告警聚合与降噪（如静默、分组）。
- **智能告警策略**：基于历史数据自动生成动态阈值，减少误报；支持告警升级机制（如 10 分钟未响应自动升级至值班经理）。

### 操作流程
1. 在 Prometheus 配置文件中添加目标端点（如 `192.168.1.10:9090/metrics`）。
2. 通过 MYOps 界面创建告警规则（如 `CPU > 80%`），选择通知渠道。
3. 告警触发后，系统自动发送消息并生成工单。

---

## 场景三：日志分析

### 核心能力
- **高吞吐采集**：使用 Filebeat 采集日志，经 Kafka 缓冲（支持 10 万 TPS 峰值）后写入 Elasticsearch。
- **全文检索与聚合**：基于 ELK Stack 实现毫秒级全文搜索，支持聚合分析（如错误码分布、响应时间 P99 统计）。
- **日志上下文关联**：通过 Trace ID 关联分布式系统日志，实现端到端请求链路分析。

### 操作流程
1. 在目标主机部署 Filebeat，配置日志路径及 Kafka 地址。
2. 登录 MYOps 日志分析页面，输入查询语句（如 `status:500 AND service:api`）。
3. 在“聚合”选项卡中生成饼图、折线图；点击日志条目可查看上下文。

## 场景四：自动化部署

### 核心能力
- **GitOps 工作流**：集成 GitLab CI 进行代码构建与测试，通过 ArgoCD 同步至 Kubernetes 集群，确保环境与 Git 仓库完全一致。
- **高级发布策略**：支持金丝雀发布（逐步放量，如 5% → 20% → 100%）与蓝绿部署（瞬间切换流量），内置健康检查与自动回滚。
- **多环境管理**：开发、测试、生产环境独立配置，支持环境间配置差异比对。

### 操作流程
1. 在 GitLab 中定义 `.gitlab-ci.yml` 构建镜像，推送至 Harbor 仓库。
2. 在 ArgoCD 中创建 Application，关联 Git 仓库与 Kubernetes 命名空间。
3. 选择发布策略（如金丝雀），设置放量比例，系统自动执行并监控健康状态。

## 场景五：成本优化

### 核心能力
- **多云统一 Dashboard**：通过 AWS Cost Explorer API 和阿里云 BSS API 采集账单数据，在单一界面展示总花费、按服务/标签/区域分解的成本。
- **资源利用率分析**：关联 CMDB 与监控数据，识别闲置资源（如 CPU 使用率低于 10% 的实例），推荐降配或释放。
- **预算与告警**：设定月度预算阈值，超支时自动触发告警（可关联场景二的告警通道）。

### 操作流程
1. 在 MYOps 中配置 AWS 及阿里云账号凭证（只读权限）。
2. 系统自动同步账单数据，Dashboard 展示过去 30 天成本趋势。
3. 进入“优化建议”页面，查看系统推荐的资源调整方案（如“关闭测试环境 3 台 t3.medium”）。

---

## 集成与扩展

- **API 开放**：所有场景提供 RESTful API，支持与内部工单、审批系统集成。
- **插件市场**：支持自定义 Exporter、告警通知模板及成本分析规则。

## 总结

MYOps 通过五大场景的有机整合，实现从“被动响应”到“主动运维”的转变。配置自动发现奠定数据基础，监控与日志提供实时洞察，自动化部署保障交付效率，成本优化则推动资源精细化管理。建议企业按“配置→监控→日志→部署→成本”的顺序逐步落地。
